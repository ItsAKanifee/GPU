## What is a GPU

A GPU is a processing unit, made to run multiple instructions in parallel

### GPU vs CPU
- CPUs perform fewer yet mmore complicated instructions at a time; GPUs perform many yet more simple instructions at a time
- CPUs are better suited to run a variety of tasks; GPUs can run a very small amount of tasks such as arithmetic
- CPU speed is measured by clock cycle; GPU speed is measured by FLOPs (Floating Point Operations Per Second)
