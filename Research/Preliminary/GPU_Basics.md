## Summary

### CPUs vs GPUs

- CPUs
    - Few calculations that can be performed at a faster rate
        - Faster rate is due to complex memory hierarchy optimized to reduce latency
    - CPU operations are more flexible and robust

- GPUs
    - Many calculations that are performed at a slower rate
    - GPU operations are more rigid and suited for certain things
        - Can only run basic instructions like arithmetic
