# Research

## Purpose

This project is dedicated to collecting research, notes, and references related to the design and implementation of a custom GPU. It serves as a knowledge base to inform the prototyping and development process.

## Contents

- Summaries of articles, papers, and books on GPU architecture
- Notes on FPGA implementation strategies
- Comparisons of open-source GPU projects
- Documentation of relevant SystemVerilog features
- Links to useful resources and tutorials
- Diagrams and block-level sketches
- Limitations to keep note of in preparation for 525

## How to Use

- Add new findings, insights, or references as you progress
- Write down notes in Docx, PDF, and Markdown
- Organize content by topic or theme for easy navigation
- Keep track of questions and challenges encountered during research
