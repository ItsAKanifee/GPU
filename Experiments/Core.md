# Core

The entire GPU architecture starts at the core, i.e the part that does the floating point operation. 

## Goals
- Find a way to make a simple hardware path to operate on floating point values
    - Addition
    - Multiplication
- Figure out how to expand for parallel use

- After looking up what a double adder looks like, it is clear that will not be a trivial process
    - Learn how to implement one in hardware
